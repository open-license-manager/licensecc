# Contributing to Licensecc

Contributions are what keep this project alive. See [MAINTENANCE.md](http://open-license-manager.github.io/licensecc/v2.1.0/other/maintenance.html) for ways to help beyond code — answering questions, reviewing PRs, testing, documentation, or becoming a maintainer.

## Questions & Discussions

Use [GitHub Discussions](https://github.com/open-license-manager/licensecc/discussions) — the preferred channel for questions, ideas, and community support.

## Reporting Bugs

Open a [GitHub issue](https://github.com/open-license-manager/licensecc/issues) with label `bug`. Check for existing issues first. Include:

- **Steps to reproduce** — exact commands, code snippets, or a minimal test case.
- **Expected vs. actual behavior**.
- **Environment**: OS, compiler (host/target if cross-compiling), cmake command line, VM/Docker if applicable.
- **Licensecc version** — try the latest `develop` branch first.

A unit test demonstrating the bug is ideal.

## Suggesting Enhancements

Check [existing requests](https://github.com/open-license-manager/licensecc/issues?q=is%3Aissue+label%3Aenhancement) and the [feature wiki](https://github.com/open-license-manager/licensecc/wiki/features) first. Open an issue to discuss before implementing.

## Pull Requests

- **Small fixes** (docs, trivial bugs): submit directly with a short description.
- **Larger changes**: open an issue first to discuss the approach.
- **Branch**: always PR from a **separate feature branch** in your repository — never from your `develop`.
- **Style**: use the provided `.clang-format`. Do not reformat unrelated code.
- **Scope**: keep PRs focused. Large, undocumented PRs with no linked issue will be rejected.

## Getting Started

Look for [`good first issue`](https://github.com/open-license-manager/licensecc/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22) or [`help wanted`](https://github.com/open-license-manager/licensecc/issues?q=is%3Aopen+is%3Aissue+label%3A%22help+wanted%22). If an issue is assigned, comment first to avoid duplication.
