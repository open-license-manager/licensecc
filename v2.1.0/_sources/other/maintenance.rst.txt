#################################
Maintenance Status
#################################

.. attention::

   **Status: Seeking maintainers**

As of 2026, Licensecc is a volunteer project maintained by a single developer in his
spare time (I stopped coding 6 years ago, and the project for which this library was
created in the first place is long gone...). While the library is stable and functional,
response times for issues, pull requests, and feature requests may be significantly
delayed.

*****************
What this means
*****************

* **Bug fixes and PRs** are reviewed and merged when possible, but there is no fixed
  schedule.
* **New environment support** is unlikely unless contributed by the community.
* **Commercial support** is not available.

*****************
How you can help
*****************

The project is actively looking for additional maintainers. If you use Licensecc and
would like to help keep it healthy, consider:

* Helping other people by answering questions in the forums
* Reviewing and commenting on open pull requests
* Testing the system on your environment and validating existing issues
* Provide support for new environments or new compilers (submit a PR with your
  github action)
* Helping with documentation improvements
* Contacting us via `discussions <https://github.com/open-license-manager/licensecc/discussions>`_
  if you are interested in becoming a maintainer
